# Contributing

Thank you for your interest in contributing to this project. We welcome help from the community and appreciate thoughtful contributions.

## Ways to contribute

There are a few easy ways to get involved:

- Open an issue to report a bug, suggest an improvement, or ask a question
- Open a pull request with a fix, enhancement, or documentation update
- Share feedback or ideas that could improve the project

If you are unsure where to start, feel free to open an issue and ask. We are happy to help point you in the right direction.

## Before you start

- Check whether a similar issue or pull request already exists
- Keep your changes focused and easy to review
- Write clear commit messages and descriptive PR titles
- Include context when proposing changes, especially for non-trivial updates

## Pull requests

We welcome pull requests for:

- Bug fixes
- New features
- Documentation improvements
- Refactors that improve clarity or maintainability

Please keep your PRs as focused as possible and include enough detail for reviewers to understand the change and its purpose.

## Issues

If you want to report a problem or suggest an improvement, please open an issue with as much relevant detail as possible, including:

- a clear description of the problem or request
- steps to reproduce, when applicable
- expected vs. actual behavior
- any relevant environment or version information

## Questions

If you have questions, want to discuss an idea, or are not sure whether something is needed, please open an issue or start a discussion. We welcome questions and are happy to help.

## Community expectations

Please be respectful, constructive, and collaborative. We aim to maintain a welcoming environment for contributors of all experience levels.

Thank you for helping make this project better.
